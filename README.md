# Album Mundial

## Resumen
El proyecto consiste en una aplicacion para el album del mundial donde el usuario tiene un album que completar , con un sistema de cambio de cartas repetidas y otro sistema de sobres de cartas aleatorias , esto permite al usuario completar el album de manera frenetica y dinamica.

La aplicacion esta desarrollada para funcionar tanto en aplicaciones de escritorio como en aplicaciones moviles.

## Tecnologias
### Base de Datos
- PostgreSQL 
- NeonPostgres (Sistema de alojamiento de base de datos Postgres en la nube)

### BackEnd
- Quarkus 
- Hibernate & JPA

### FrontEnd
- Flutter + Material Design
